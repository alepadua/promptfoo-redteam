Executive Summary: Enterprise GenAI in Microsoft 365
Microsoft Copilot indexes the enterprise Semantic Index via Microsoft Graph, interacting with emails (Exchange), chats (Teams), documents (SharePoint/OneDrive), and corporate directories. The greatest threat is Oversharing & Permissions Creep combined with Indirect Prompt Injection. An effective assessment requires testing both deterministic tenant governance (Purview, Entra ID, ACLs) and adversarial conversational probing (Promptfoo).

Phase 1: Identity, Conditional Access & Entra ID Governance

Conditional Access & MFA Policies
  • Mandatory MFA: Enforce Phishing-Resistant MFA (FIDO2 / Windows Hello) for all accounts entitled to Microsoft 365 Copilot.
  • Compliant Device Requirement: Block Copilot access from personal or unmanaged devices (require Microsoft Intune compliance).
  • Continuous Access Evaluation (CAE): Validate that revoked accounts or password resets terminate active Copilot sessions immediately.
Copilot License & Scope Assignment
  • Targeted License Assignment: Prevent tenant-wide auto-licensing. Ensure Copilot licenses are provisioned only to validated security-cleared users.
  • Service Principal Audits: Audit third-party apps with high-privilege Microsoft Graph API permissions (e.g. Mail.Read, Files.Read.All).

Phase 2: SharePoint & OneDrive Oversharing Remediation

Copilot does not bypass permissions; rather, it surfaces whatever the user can already access. The primary risk is legacy oversharing:

  • Broad Access Links Audit: Identify all SharePoint document libraries shared with "Everyone", "Everyone except external users", or public link access. Restrict default permissions to designated security groups.
  • Restricted SharePoint Search (RSS): Configure Restricted SharePoint Search in tenants undergoing permission remediation to limit Copilot's indexing to a curated list of approved sites.
  • Direct Access Verification: Create a mock confidential HR payroll site without general access. Confirm standard accounts querying Copilot cannot retrieve or summarize any documents from this library.

Phase 3: Microsoft Purview Sensitivity Labels & DLP Enforcement

Validate that content protection policies explicitly prevent unauthorized processing and transmission:

  • Encrypted Sensitivity Labels: Apply labels with Rights Management encryption (e.g. "Strictly Confidential - Finance"). Verify that users without decryption rights receive empty summaries when referencing labeled files in Copilot.
  • Purview Data Loss Prevention (DLP): Validate DLP rules that block Copilot from including credit card numbers, tax IDs, or passwords in chat responses.
